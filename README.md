 Sales Analysis & Interactive Excel Dashboard

 Project Description

Created an interactive Sales Analysis Dashboard using Microsoft Excel to analyze revenue, quantity sold, monthly sales, regional performance, and item-wise sales.

The project uses PivotTables and data visualization to summarize sales data and present key insights through an interactive dashboard.

 Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Data Visualization
- Interactive Dashboard

 Dataset

The dataset contains sales-related information including:

- Date
- Customer
- Region
- Item
- Quantity
- Price
- Amount

 Analysis Performed

- Total Revenue Analysis
- Total Quantity Sold
- Monthly Sales Analysis
- Region-wise Sales Analysis
- Item-wise Sales Analysis
- Sales Performance Comparison

 Workbook Structure

 Data
Contains the original sales data used for the analysis.

 Pivot Table
Contains PivotTables created to summarize and analyze the sales data.

 Dashboard
Contains the interactive Excel dashboard with charts and key sales metrics.

 Key Metrics

- Total Revenue
- Total Quantity Sold
- Sales by Region
- Monthly Sales
- Item-wise Sales

 Project Objective

The objective of this project is to analyze sales data using Microsoft Excel and create a clear, interactive dashboard that helps users understand sales performance and identify important sales trends.
